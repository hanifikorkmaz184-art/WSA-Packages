Windows Subsystem for Android ve ilgili yazılımlar Microsoft Corporation'a aittir.

Bu proje Microsoft'a ait değildir ve Microsoft tarafından desteklenmemektedir.

Biz yalnızca WSA paketlerini arşivliyor ve dağıtıyoruz.

Tüm marka, ticari marka ve telif hakları ilgili sahiplerine aittir.
